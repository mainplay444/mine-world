🎮 Как зайти на сервер

🟩 Java Edition

1. Открой Minecraft Java Edition.
2. Перейди в «Сетевая игра».
3. Нажми «Добавить сервер».
4. Введи IP сервера:

5. Нажми «Готово» и подключись.
